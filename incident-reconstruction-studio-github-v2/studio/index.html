Project and scene

Use a source image that you are authorized to use. Uploaded imagery stays in your browser session memory until you export a project file.

Movement routes

Create any number of routes for people, vehicles, or objects. Add or select a route, enable plotting mode, then click or tap the scene to place numbered waypoints in sequence.

Scene markers and annotations

Choose a marker type, activate placement mode, and click or tap the scene. Use the Edit button in the marker list to revise labels or source notes at any time.

Injury-area symbols are illustrative annotations only. They do not establish a diagnosis, injury boundary, mechanism, or medical conclusion.

Review and export
