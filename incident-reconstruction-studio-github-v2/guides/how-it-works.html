Operational Guide

How Incident Reconstruction Studio Works

Follow the six built-in workflow tabs to assemble a transparent, reopenable visual scene exhibit without installing desktop software or uploading files to a remote database.

Step 1: Project Metadata & Base Scene

Enter your project title, incident category, case reference ID, preparer attribution, and scene notes. Upload any browser-supported image (JPG, PNG, WebP) such as an aerial screenshot, diagram scan, or site photograph—or work directly over the built-in coordinate grid.

Step 2: Plotting Movement Routes

Name each entity (for example, Vehicle A or Pedestrian 1), pick a distinct color, and select Add route & start plotting. Click or tap sequentially on the canvas to place numbered waypoints. Use Undo last route point to step back, switch active routes from the dropdown or sidebar, and press Esc when finished plotting.

Step 3: Placing & Editing Scene Markers

Select one of five structured marker categories—Event / occurrence, Contact / interaction point, Reported injury area, Reference / evidence point, or Area of interest—enter a label and source note, then click the scene to place it. You can rename or update any marker directly from the right-hand Markers list using the Edit button.

Step 4: Building the Event Chronology

Record time stamps or sequence numbers alongside concise descriptions of what source materials document. When you print the exhibit, this chronology formats automatically into a clean table beneath the scene diagram.

Step 5: Classifying the Evidence Register

Log every supporting document, photograph, video clip, measurement, or statement with a unique ID (such as E-01) and tag it under one of four evidentiary categories:

  • Documented fact — directly reflected in verified records or measurements
  • Expert interpretation — technical analysis provided by a qualified specialist
  • Assumption — working premise required to illustrate a scenario
  • Unresolved / disputed — conflicting accounts or unverified claims

Step 6: Reviewing & Exporting Deliverables

Inspect your canvas using the zoom controls (-, +, and Fit scene), then choose from four output formats:

Output FormatWhat It ContainsPrimary Use
PNG Exhibit1400×800 rendered scene canvas with routes, markers, and footer barSlide decks, mediation briefs, visual attachments
Printable ExhibitRendered diagram paired with notes, chronology table, and evidence registerPhysical binders, depositions, PDF print-to-file
Project JSONComplete editable state including base image, coordinates, and logsArchiving and reopening projects in the Studio
Summary CSVStructured spreadsheet listing routes, markers, timeline, and evidence itemsCase management imports and audit trails
