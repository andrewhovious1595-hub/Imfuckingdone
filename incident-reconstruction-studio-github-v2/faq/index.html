Support & Technical Answers

Frequently Asked Questions

Direct answers regarding the Studio workspace, local browser privacy, export formats, project saving, and evidentiary boundaries.

What kind of software is Incident Reconstruction Studio?

Incident Reconstruction Studio is a responsive, browser-based visual exhibit builder. It lets you upload an authorized scene photograph, map, or plan, plot independently colored numbered movement routes, place editable scene markers, build an event chronology, maintain a classified evidence register, and export PNG, printable, JSON, and CSV deliverables.

Does the application upload my case photos or evidence to a server?

No. The Studio runs entirely client-side in your browser. Uploaded scene imagery and project data stay in local browser page memory until you export them. You should store exported JSON, PNG, and CSV files using your organization's approved secure storage.

Can I try the Studio before payment or licensing is finalized?

Yes. You can use the full 6-step Studio workspace directly in your browser right now. Export actions route through an integrated Export Access Checkpoint designed to connect cleanly to a payment provider once commercial licensing is configured.

Can I save my work and reopen it later for revisions?

Yes. Use Save project or Download project JSON in Step 6 to save a self-contained JSON file (which includes your routes, markers, timeline, evidence register, and uploaded base image). Click Open project in the Studio toolbar anytime to reload and keep editing.

Does the Studio perform forensic physics calculations or establish causation?

No. It is an illustrative visual exhibit builder, not forensic collision dynamics or medical diagnostic software. All geometry, routes, labels, and chronology entries are user-entered visualizations. Technical conclusions should always be reviewed by appropriately qualified experts.

Can I edit marker labels or route names after placing them?

Yes. Both the Routes panel and Markers panel in the Studio sidebar include Edit buttons so you can update labels, names, and source descriptions without deleting and recreating points.

Does it work on tablets and mobile devices?

Yes. Both the multi-page website and the Studio workspace use a responsive layout that adapts to desktop, tablet, and mobile viewports, supporting tap-to-place points and touch-friendly controls.
